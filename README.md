## 🚀 Perfil e Experiência

Sou um Engenheiro de Software especializado no ecossistema **JavaScript e TypeScript**, com foco na construção de sistemas escaláveis, APIs de alta performance e interfaces de usuário otimizadas. Transformo requisitos complexos em soluções técnicas eficientes, mantendo o foco em boas práticas, clean code e arquitetura sustentável.

* **Arquitetura e Backend:** Desenvolvimento de APIs RESTful robustas e microsserviços utilizando **Node.js, Express e Fastify**. Modelagem de dados avançada e eficiente utilizando **PostgreSQL** com **Prisma ORM**.
* **Frontend Moderno:** Criação de interfaces reativas, acessíveis e de alta performance com foco em UX/UI utilizando **React.js** e **Tailwind CSS**.
* **Inteligência Artificial:** Integração prática de IA em produtos de software, utilizando a **API da OpenAI** para automatizar processos complexos e gerar alto valor agregado aos negócios.
* **DevOps e Infraestrutura:** Controle de versão ágil com **Git**, conteinerização avançada com **Docker** para garantir consistência entre ambientes de desenvolvimento e produção.
